Features

Everything an MSP needs for session management, nothing it doesn't.

⚙

WTS Win32 P/Invoke

Direct WTSEnumerateSessions calls — no quser.exe parsing fragility, no locale bugs, no truncated session IDs.

⚡

Parallel Scanning

RunspacePool fan-out scans hundreds of servers concurrently. Throttle-controlled, PS 5.1-compatible. No ForEach-Object -Parallel required.

☃

Zero Dependencies

Pure PowerShell + built-in .NET. No ActiveDirectory RSAT module. Runs out-of-box on any domain-joined Windows host.

★

ANSI Dashboard

256-color terminal UI with box-drawing panels, status glyphs, idle-time heat coloring, and Cylon-style async logoff progress bars.

✎

Ticket-Ready Reports

Markdown (clipboard) and self-contained neobrutal HTML (browser). Paste directly into HaloPSA, ConnectWise, or any ticket system.

⚠

Disabled User Detection

Flags sessions for disabled AD accounts — the gap between disabling an account and ending its sessions. Offboarding visibility built in.

✽ · ✽ · ✽

PowerShell API

Three cmdlets. One domain. Complete control.

Find-UserSession Find

Emit session objects for pipeline composition. Filter by user, OU, computer, or LDAP query.

# Find idle disconnected sessions Find-UserSession -Username jmariano | Where-Object { $_.IdleTime.TotalDays -gt 7 }
Show-UserSession Show

Rich dashboard with optional async logoff and report generation. The daily driver.

# Scan, logoff, report — one command Show-UserSession -LogOff -Confirm:$false ` -Report markdown
Stop-UserSession Stop

Pipeline-bound single-session logoff with full ShouldProcess support. Surgical precision.

# Pipe stale sessions to logoff Find-UserSession | Where-Object State -eq Disconnected | Stop-UserSession -Confirm:$false

Reports

Ticket-ready artifacts, generated in one command.

Markdown

MD

Clean GitHub/HaloPSA-friendly tables. Copies straight to clipboard by default.

  • Operator identity & timestamp
  • Scope description
  • Per-server session tables
  • Logoff result tally
  • Disabled user section
  • Offline & errored hosts

  • No external dependencies

Safety First

Guardrails baked into every destructive path.

⭐

Own-Session Guard

Logoff commands skip your current session unconditionally. You cannot log yourself out.

🧪

ShouldProcess

Full -WhatIf and -Confirm support. Bulk logoffs use a single batch-level confirmation prompt.

🔒

Read-Only Default

Show-UserSession without -LogOff is pure display. No side effects, ever.

📜

Audit Trail

Reports include operator identity, timestamp, scope, and outcome counts. Attach to tickets for compliance.

🌐

No External Deps

Pure PowerShell + built-in .NET. No network calls, no telemetry, no supply chain risk.

⚠

Offboarding Visibility

Disabled AD accounts with live sessions are flagged in both dashboard and reports. Find the gaps.
