# Brand assets

Drop the module's brand PNG here. The README references `usersessions-icon.png`
(256x256 minimum, transparent background recommended).

Billboard's convention is:
- `usersessions-icon.png` — square icon for headers
- `usersessions-wordmark.png` — horizontal lockup for footers

Until a designer produces real marks, the README renders fine without them
(the badges and typography carry the brand).
